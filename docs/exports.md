# Exports

What this mod offers other mods, which is what `LICENSE.EXCEPTION` names as
the interface an independent work may use: everything offered through
`game.export`, the hooks, events and chat words it accepts, the data formats
it reads and writes, and the identifiers it registers. Nothing yet — the mod
is a scaffold. Recipes, the chest, the kiln and the tools go here as they
land, each with the id, the shape of the table, and what the caller gets
back.
